# Yoga & Mobility

Eine Website mit 27 Lieblingskanälen, Suche, Kategorien und direkter Weiterleitung zu YouTube.

GitHub Pages veröffentlicht die Website aus dem Stammverzeichnis des Branches `main`. Auf dem iPhone lässt sie sich in Safari über **Teilen → Zu Home-Bildschirm hinzufügen** als Web-App ablegen.
